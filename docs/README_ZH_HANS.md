# Yumehub

> **Yumehub** 取自 **@YumeYuka** 的 **Yume** 和 **GitHub** 的 **hub**

Yumehub 是一个为了解决 GitHub Mobile For Android (Github 官方应用) 的缺点而开发的开源第三方客户端。支持Github Mobile 的所有功能，
目标是完全替代官方客户端,除了客户端基本功能外,未来将考虑加入一些扩展性功能

## 背景

长期以来，官方 GitHub Android 客户端的体验一直是一坨垃圾，但官方似乎根本没有修复的打算。甚至为了推销 Copilot，直接把原本应该放在导航栏的功能替换成了 Copilot Chat。这种破坏原有导航逻辑的行为几乎在每个页面都能看到。

UI 上的倒退还只是一部分，更难以接受的是性能问题。打开任何一个仓库或 PR，比内容先出现的永远是转圈。与其等待官方的修复优化,不如就此彻底重写一切.
